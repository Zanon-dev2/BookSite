# 📚 BookSite — Biblioteca JM

Um protótipo de biblioteca digital para leitura e acesso a livros em PDF, desenvolvido inteiramente em um único arquivo HTML com CSS e JavaScript integrados.

## 📖 Sobre o Projeto

A **Biblioteca JM** (*"Um site dedicado aos leitores!"*) é uma aplicação front-end leve e prática que reúne um acervo variado de livros digitais (ficção, desenvolvimento pessoal, ciência, engenharia, entre outros). Por concentrar toda a estrutura, estilização e scripts em uma única página (`index.html`), o projeto oferece carregamento rápido e facilidade para ser hospedado ou executado localmente sem dependências externas.

## ✨ Funcionalidades

* **Catálogo de Livros:** Exibição organizada de diversos títulos disponíveis no acervo.
* **Barra de Pesquisa:** Filtro dinâmico para encontrar rapidamente obras específicas no catálogo.
* **Modo Escuro (Dark Mode):** Alternância de tema visual para proporcionar mais conforto durante a leitura e navegação.
* **Estrutura Single-File:** Código HTML, CSS e JS unificados para máxima portabilidade.

## 🚀 Tecnologias Utilizadas

* **HTML5** — Estruturação da interface, cabeçalho e lista do acervo.
* **CSS3 (Interno)** — Estilização da página, layout dos cartões e suporte ao tema escuro.
* **JavaScript (Interno)** — Lógica da barra de busca e alternância do modo escuro.

## 💻 Como Executar

Você pode rodar o projeto diretamente no navegador sem precisar instalar servidores ou pacotes:

1. Clone este repositório:
   ```bash
   git clone https://github.com
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd BookSite
   ```
3. Dê um duplo clique no arquivo `index.html` para abri-lo no seu navegador de preferência.
